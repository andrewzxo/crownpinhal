     7→### Tipos (src/lib/types.ts)
     8→- `SessionUser`: { id, name, email, phone?, role: 'CLIENT'|'ADMIN'|'OWNER' }
     9→- `ScheduleDTO`: { id, dayOfWeek, startTime, endTime, instructor? }
    10→- `ModalityDTO`: { id, name, description, imageUrl?, icon?, order, active, schedules: ScheduleDTO[] }
    11→- `PlanDTO`: { id, name, description, features: string[], price: number|null, period?, badge?, highlighted, order, active }
    12→- `GalleryDTO`: { id, url, title?, order, active }
    13→- `ContentResponse`: { settings: Record<string,string>, modalities: ModalityDTO[], plans: PlanDTO[], gallery: GalleryDTO[] }
    14→
    15→### APIs ( todas retornam JSON; erro = { error: string } + status )
    16→- POST /api/auth/register {name,email,password,phone} → {user: SessionUser}
    17→- POST /api/auth/login {email,password} → {user: SessionUser}
    18→- POST /api/auth/logout → {ok}
    19→- GET  /api/auth/me → {user|null}
    20→- GET  /api/content → ContentResponse
    21→- POST /api/subscriptions {planId, notes?} (requer login) → {subscription}
    22→- GET  /api/subscriptions/mine → {subscriptions}
    23→- Admin (role ADMIN ou OWNER): /api/admin/modalities (+ /api/admin/modalities/[id] PUT/DELETE), /api/admin/schedules (+[id]), /api/admin/plans (+[id]), /api/admin/gallery (+[id]), PUT /api/admin/settings, POST /api/admin/upload (multipart, campo "file") → {url}
    24→- Owner (role OWNER): GET /api/owner/stats, GET /api/owner/users, PUT/DELETE /api/owner/users/[id], GET /api/owner/subscriptions, PUT/DELETE /api/owner/subscriptions/[id]
